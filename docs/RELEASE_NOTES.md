Panorama 0.1.0 is the first personal-use preview.

- Horizontal overview with live window previews and snapshot mode.
- Separate scroll-position and explicit-selection indicators.
- Compact thumbnail/icon navigator and Dock clearance.
- Configurable shortcut and optional four-finger trackpad activation.
- Native Settings, system/custom accent and Liquid Glass fallback.
- Local performance benchmark and signed Sparkle update integration.

Requires macOS 14+, Screen Recording, and Accessibility permissions. Four-finger activation uses an undocumented macOS interface; configure conflicting macOS desktop gestures in Trackpad settings. App builds without a Developer ID certificate are ad hoc signed and not notarized. Physical gestures, permissions, and update installation require testing on the target Mac.
